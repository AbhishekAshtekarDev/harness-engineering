# Skills

`harness-review/` is an [Agent Skill](https://agentskills.io/specification) that reviews a repository's harness against the [course checklist](../reference/harness-checklist.md). Copy the folder into your agent's skills directory (for Claude Code, `.claude/skills/harness-review/` in your project or `~/.claude/skills/harness-review/`), then ask: "Review the harness in this repo."
